# Reel Script Studio: دليل الاستخدام بالعربية

الإصدار: **2.2.2** · إعداد: يوسف الجبوري (@yousif_aljbouri) · تحديث الدليل: 26 أكتوبر 2026.

[تحميل ملف المهارة ZIP](https://github.com/joe7182/reel-script-studio/releases/download/v2.2.2/reel-script-studio-2.2.2.zip) · [الشرح على الموقع](https://yousifaljbouri.com/tutorials/reel-script-studio)

## ما هي الأداة؟

Reel Script Studio هي مهارة (Skill) تعمل داخل Claude. تعطيها فكرتك أو سكربتك، فتتعامل معه كما يتعامل فريق كتابة متكامل:

- تبحث قبل أن تكتب: تعرف الزوايا المكررة في موضوعك حتى لا تعيدها، وتتحقق من المعلومات.
- تدقّق سكربتك ثانية بثانية: أين قد يغادر المشاهد، ولماذا.
- تكتب ٥ افتتاحيات (Hooks) و٣ خيارات لكل جزء من السكربت.
- «عقل المشاهد»: تحاكي ثلاثة مشاهدين أثناء مشاهدة أول ٣ ثوانٍ من كل افتتاحية: ماذا يرون، وماذا يسمعون، وبماذا يفكرون، وهل يبقون أم يغادرون. والافتتاحية التي تحافظ عليهم هي التي يقع عليها الاختيار.
- تفحص السكربت برمجياً: المدة، والعبارات المكررة، والادعاءات التي بلا دليل، والكلمات الغريبة على لهجتك.
- مجلس مراجعة من ٥ زوايا (الاستراتيجية، والإبداع، واللهجة، والأداء، والمصداقية) قبل أن يصلك أي شيء.
- تسلّمك لوحة تفاعلية (Dashboard) فيها كل ما تحتاجه للتسجيل والنشر.

وهي صريحة معك: إذا كانت فكرتك ضعيفة تخبرك بذلك بوضوح وتقترح بديلاً أفضل، لكن القرار يبقى لك. وإذا اخترت فكرتك كما هي، تكتبها بأفضل صورة ممكنة.

## ماذا تحصل في النهاية؟

لوحة بصيغة HTML تفتحها في أي متصفح، وتحتوي على:

| القسم | المحتوى |
| --- | --- |
| الاستوديو | اختر سطراً لكل جزء، ويتحدّث التوقيت فوراً. نسخ، وتنزيل .txt، وترجمة .srt، وملقّن (Teleprompter) يقيس سرعتك الحقيقية في الكلام |
| الخلاصة | فكرة الريل في سطر واحد، والمقارنة بين سكربتك الأصلي والنتيجة، و«بصمتك» (أسلوبك في الكلام وما تقوله أرقامك) |
| الفكرة | تقييم الفكرة، والمصادر التي قُرئت مع روابطها، والزاوية المكررة التي تجنّبناها |
| التدقيق | الملاحظات ثانية بثانية، وكل ملاحظة مبنية على أساس واضح: مصدر، أو أرقامك، أو قاعدة معروفة في الكتابة |
| عقل المشاهد | محاكاة أول ٣ ثوانٍ: افتتاحيتك الأصلية مقارنةً بالافتتاحية المختارة |
| المجلس | فريق المراجعة وقراراته |
| ElevenLabs | نص جاهز للتعليق الصوتي بالذكاء الاصطناعي، مع وسوم اللهجة والإعدادات المقترحة |
| الأداء | كيف تلقي كل سطر: مستوى الطاقة، والكلمة التي تركّز عليها، والسرعة |
| التصوير | جدول اللقطات، وأول لقطة، والغلاف، وترتيب التسجيل |
| النشر | تعليق (Caption) يضيف قيمة ولا يكرر السكربت، وهاشتاغات، وتعليق مثبّت |

وبعد الاستخدام الأول تحصل أيضاً على ملف creator-profile.json، وهو بصمتك المحفوظة، حتى لا تتكرر الأسئلة في المرات القادمة.

## المتطلبات

- حساب Claude على claude.ai (من المتصفح أو تطبيق Claude Desktop).
- تفعيل تنفيذ الأكواد (Code execution). الأداة تفحص السكربت بالكود وتبني اللوحة. وبدونه ستخبرك بذلك وتتوقف، ولن تزيّف النتيجة.
- يُنصح بتفعيل البحث في الويب (Web search) لتبحث الأداة قبل أن تكتب. وبدونه تعمل بقواعد الكتابة وأرقامك فقط، وتخبرك بذلك بوضوح.

الأداة لا تعمل على ChatGPT، فهي مصممة لـ Claude.

## التثبيت (مرة واحدة فقط)

### ١. فعّل الأدوات

ادخل إلى claude.ai ← Settings (الإعدادات) ← Capabilities، وفعّل:

- ✅ Code execution and file creation
- ✅ Web search

### ٢. حمّل الأداة

حمّل `reel-script-studio-2.2.2.zip` من رابط التحميل أعلى الدليل. لا تفك الضغط عنه عند رفعه إلى Claude؛ ارفعه كما هو.

### ٣. ارفع المهارة

افتح Customize ← Skills، ثم زر + ← Create skill ← Upload a skill، وارفع ملف ZIP دون فك الضغط. تأكد أن المهارة ظاهرة باسم reel-script-studio وأن زرّها مفعّل. فعّل Code execution and file creation من Settings ← Capabilities؛ قد يظهر باسم Create and edit files في الواجهة المحدّثة.

إذا كانت لديك نسخة قديمة، احذفها أولاً ثم ارفع النسخة الجديدة.

## الاستخدام لأول مرة

### ١. افتح محادثة جديدة واكتب طلبك

يمكنك الكتابة بلهجتك أو بالفصحى. وللتأكد من تشغيل المهارة، ابدأ رسالتك باسمها:

```text
استخدم مهارة Reel Script Studio.
لدي سكربت ريل، حسّنه لي:
[الصق سكربتك هنا]
```

وإذا كانت لديك فكرة فقط:

```text
استخدم مهارة Reel Script Studio.
لدي فكرة ريل عن [فكرتك]
```

وإذا أردت الحفاظ على شيء محدد، فاذكره صراحةً، مثل: «حافظ على اسم السلسلة «…» وكلمة التعليق «…»». الأداة ملزمة بالحفاظ عليه.

### ٢. أجب عن الأسئلة (في المرة الأولى فقط)

ستطرح عليك في رسالة واحدة سبعة أسئلة على الأكثر، ولكل سؤال خيارات جاهزة:

- مستوى اللهجة: لهجة محلية قوية، أو لهجة مبسطة يفهمها كل العرب، أو فصحى مبسطة.
- مجالك وجمهورك ونوع محتواك (تقنية، تعليم، طبخ، سفر…).
- ريلان من محتواك (اختياري، لكنه يُحدث فرقاً كبيراً): واحد نجح وآخر لم ينجح. الصق شاشة الإحصائيات (Insights) كما هي، والكلام الذي قلته في الفيديو.
- أسلوبك في الكلام: عفوي، أو معلوماتي ممتع، أو هادئ (ASMR)، أو احترافي، أو حماسي، أو ساخر جاف، أو راوٍ هادئ.
- طريقة التسجيل: بصوتك، أو تعليق صوتي على تسجيل شاشة، أو صوت من ElevenLabs.
- منصة النشر: إنستغرام، أو تيك توك، أو يوتيوب شورتس.
- قصة أو رقم حقيقي من عملك (اختياري).

أجب بإيجاز مع الترقيم، مثلاً:

```text
١. لهجة خليجية مبسطة
٢. تقنية، جمهوري شباب يعملون بشكل حر، محتوى تعليمي
٣. لا يوجد حالياً
٤. معلوماتي ممتع
٥. صوتي على تسجيل شاشة
٦. إنستغرام
٧. لا يوجد
```

أو اكتب «تابِع»، فتستخدم الأداة الإعدادات الافتراضية.

### ٣. انتظر حتى تنتهي

تستغرق العملية بضع دقائق، لأن الأداة تبحث وتكتب وتفحص وتراجع. وفي النهاية تسلّمك:

- 📄 ملف اللوحة (Dashboard HTML): حمّله وافتحه في المتصفح.
- 👤 ملف creator-profile.json: حمّله واحتفظ به.

## في المرات القادمة

ارفع ملف creator-profile.json مع رسالتك:

```text
استخدم مهارة Reel Script Studio. هذا ملفي. لدي فكرة ريل جديدة عن …
```

لن تتكرر الأسئلة الطويلة، وستسألك فقط عن هدف الريل، والإثبات المتوفر لديك، وأسلوب هذه المرة.

## طرق أخرى للاستخدام

| ما تريده | ما تكتبه |
| --- | --- |
| تدقيق فقط دون كتابة سكربت جديد | «دقّق هذا السكربت فقط، ولا تكتب سكربتاً جديداً: …» |
| تصحيح سريع (إملاء، أو سطر واحد) | «صحّح الإملاء فقط: …» |
| نسخة سريعة بمراجعة أخف | اكتب كلمة «سريع» في رسالتك |
| تعليق صوتي من ElevenLabs | «استخدم ElevenLabs v3» (أو النموذج الذي تستخدمه) |

## «عقل المشاهد»: كيف تقرؤه؟

تتخيّل الأداة ثلاثة مشاهدين محددين:

- 🎯 المستهدف: الشخص الذي صُنع الريل من أجله.
- 👤 الغريب: لا يعرفك ولا يتابعك، وقد يشاهد دون صوت.
- 🤨 المتشكك: شاهد هذا الموضوع عشرات المرات، ويغادر عند أول جملة مكررة.

ولكل افتتاحية ترى، ثانية بثانية (٠، ١، ٢، ٣): ماذا يرى المشاهد، وماذا سمع حتى الآن، وبماذا يفكر، وهل يبقى أم يغادر. ويمكنك مقارنة افتتاحيتك الأصلية بالافتتاحية المختارة.

⚠️ هذه محاكاة مبنية على البحث وعلى أرقامك، وليست توقعاً. لن تقول لك الأداة أبداً «ستحصل على كذا مشاهدة». هي تشرح لك لماذا يبقى المشاهد أو يغادر، والقرار لك.

نصيحة: إذا كنت تعرف معدل التخطي (Skip rate) من إحصائيات إنستغرام لريلزك، فالصقه مع الإحصائيات؛ فهو أدق رقم عن أول ٣ ثوانٍ.

## حدود الأداة (بكل صراحة)

- تقرأ النص وتحسب التوقيت، لكنها لا تسمع صوتك ولا نبرتك.
- لا تتوقع المشاهدات ولا الوصول ولا الانتشار أبداً.
- لا تخترع قصصك ولا أرقامك. إذا لم يكن لديك تفصيل حقيقي، تكتب سكربتاً قوياً بدونه، أو تطلب منك التفصيل بوضوح.
- لا تدّعي ما لم يُقَس: لا تقول «في ثانية واحدة» أو «دون مونتاج» أو «يفهمك تماماً» ما لم يكن لديك دليل.
- المجلس نموذج واحد يراجع من خمس زوايا وفق قواعد مكتوبة، وليس فريقاً بشرياً.
- تسجّل الأداة مصادر البحث مع روابطها، لكنها لا تستطيع إثبات أنها قرأت كل صفحة كاملة.

## مشكلات شائعة وحلولها

لم تطرح عليّ أسئلة ولم تظهر لوحة؟ المهارة لم تعمل. تأكد أن زرّها مفعّل في الإعدادات، ثم افتح محادثة جديدة وابدأ بـ «استخدم مهارة Reel Script Studio».

طلبت مني تفعيل Code execution؟ ادخل إلى Settings ← Capabilities وفعّله، ثم أعد إرسال رسالتك.

ظهرت عبارة «دون بحث: قواعد الكتابة وأرقامك فقط»؟ البحث في الويب غير مفعّل. فعّل Web search إذا أردت أن تبحث الأداة قبل أن تكتب.

اللوحة لا تفتح؟ حمّل الملف إلى جهازك، ثم افتحه في متصفح مثل Chrome أو Safari أو Edge.

كلمة لا تشبه لهجتي؟ في قسم الاستوديو اضغط «تعديل» وغيّرها، وأرسل لي الكلمة لأصحّحها للجميع.

عدّلت السكربت في اللوحة فظهر تنبيه بأن التعديل لم يُفحص؟ هذا طبيعي، فالتعديل اليدوي لا يُفحص تلقائياً. أعِد السكربت إلى المحادثة إذا أردت فحصه.
